# Guides

How-to guides published at [lgkm.org/guides/](https://lgkm.org/guides/), and the lab they build.

The first series, **See**, is about visibility: what an organisation can see, from where, and what it is blind to,
using free and freemium tools. **Understand** and **Control** follow. Every guide builds one step of a lab you can run
yourself: a small, stubbed copy of Cairnmoor Outdoor, a made-up retailer, running in Docker.

- `guides/` holds the guide text (Markdown).
- `lab/` holds the lab, one step per guide.
- `public/` is what lgkm.org serves, generated from the Markdown.
